How It Works

Understand the complete workflow behind our real-time YouTube credibility verification and authorization pipeline.

The Verification Process

YT-Classifier integrates a Chrome Extension and a secure Spring Boot backend to analyze videos on the fly. Below is the step-by-step lifecycle of how a video is validated and evaluated.

1

Video ID Extraction

When you load a YouTube watch page, the extension identifies the 11-character video ID from the active URL.

2

Dual-Path Authentication Check

The request is secured using two authentication pathways:

  • Custom YID: The backend embeds your account's unique YID token in your downloaded extension configuration. If detected, the API processes requests instantly, even if you are logged out of the dashboard website.
  • Active Session Cookie: If you are using a generic anonymous extension download, the server falls back to checking your active browser session cookie.

3

Database Caching

Before running evaluations, the backend queries our SQLite database. If the video was already evaluated previously, the cached results are returned instantly to lower load times.

4

News & Informational Classification

If not cached, the server fetches details via the YouTube API. It checks the video category and keywords. Videos classified under non-informational fields (like Music, Comedy, or Sports) are marked as non-applicable and skipped.

5

Direct AI Credibility Rating

Informational videos are scored directly using the video URL and YouTube metadata via OpenRouter AI. This eliminates transcription delays, resulting in highly responsive and resource-friendly assessments.
